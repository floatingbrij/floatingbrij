### 🎯 What I Do

I build the tools that give **AI agents eyes and hands on Windows desktop applications**.

I built **[WinApp MCP (desktop-pilot-mcp)](https://github.com/floatingbrij/desktop-pilot-mcp)** — an open-source MCP server with **55 UI automation tools** that lets AI assistants like GitHub Copilot, Claude, and ChatGPT control any native Windows app. With smart caching, fuzzy matching, annotated screenshots, and support for minimized/locked windows — it goes deeper than any other Windows desktop automation MCP available today.

#### 🛠️ WinApp MCP — Playwright for Windows Desktop Apps
- 🛠️ **55 tools** for complete Windows UI automation via MCP protocol
- 🔍 Deep UI inspection with DOM-like snapshots, fuzzy matching, element search
- 🖱️ Full interaction: click, type, drag, fill forms, select dropdowns
- 📸 Visual verification with annotated screenshots & pixel-diff comparison
- ⚡ Performance-optimized with smart caching (2s descendant / 30s window TTL)
- 🪟 Works even when app is minimized or screen is locked
- 🏗️ Built with C#, .NET 8, FlaUI, and MCP 1.1.0

#### 🤖 Legacy Desktop Migration LLM Framework
- Hybrid **rule-based + multi-agent LLM** framework for automated WinForms → WinUI 3 migration
- **87.1% compilation success**, **100% UI parity**, **5,867x time reduction** over manual migration
- Five-stage pipeline: Roslyn analysis → IR → 30 rules → 4-agent LLM → output assembly
- IEEE-format research paper with evaluation across 12 test applications

#### 🎵 Hymn — Music Streaming App
- Full-stack music streaming with real-time **jam sessions** via WebSocket (Socket.IO)
- React 19 + TypeScript + Express + Firebase auth + PWA support
- Deployed on Fly.io with Docker, CI/CD via GitHub Actions
